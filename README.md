# tired-tools organization defaults

This repository contains the public organization profile and shared GitHub defaults for tired-tools.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Public README displayed on the organization's Overview page. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request template for repositories without their own template. |

## How the defaults work

GitHub uses the default pull request template for both public and private repositories in the organization when they do not have their own template. Existing pull request descriptions are unaffected.

The default is displayed by GitHub; it is not copied into project repositories or their clones. Each project can provide its own template when it needs a different format.

Changes take effect from this repository's default branch.
